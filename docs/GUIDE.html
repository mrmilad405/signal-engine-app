راهنمای خیلی ساده ✅

من بلد نیستم → پس فقط از بالا به پایین برو. لازم نیست چیزی نصب کنی، فقط مرورگر.
اول از همه: فایل repo.zip رو دانلود کن و بازش کن «Extract / Unzip». بقیهش از همین پوشه میاد.
۱ اکانت گیتهاب «اگه داری، رد شو»
برو github.com/signup → ایمیل، رمز، یه اسم کاربری. رایگانه.
۲ یه ریپوی تازه بساز
برو github.com/new و دقیقاً اینجوری پر کن:
اسم ریپو: signal-engine-app
✅ بزن Public «بخش خصوصی نباشه»
دکمهٔ Create repository رو بزن.
۳ فایلها رو بریز داخل ریپو
توی صفحهٔ ریپو: Add file → Upload files.
پوشهٔ بازشدهٔ repo رو باز کن، همهٔ محتویاتش رو بکش تو کادر آپلود «خود پوشه رو نکش؛ داخلش رو بکش».
یه پوشهٔ نقطهدار هم هست به اسم .github. اگه توی ویندوز/مک نمیبینیش، «نمایش فایلهای مخفی» رو روشن کن و اون رو هم حتماً بکش داخل. اون زنگ ۵ دقیقهایه.
پایین صفحه دکمهٔ Commit changes رو بزن.
۴Pages رو روشن کن
توی ریپو: Settings → از منوی چپ Pages.
جلوی Source بزن Deploy from a branch.
Branch: main | Folder: /docs
Save رو بزن. یکی دو دقیقه صبر کن.
۵ آدرس اپت رو پیدا کن
اسم کاربریت رو بنویس، آدرس خودش ساخته میشه:
https://نامکاربری.github.io/signal-engine-app/
اگه Pages هنوز «Visit site» نداد، ۱–۲ دقیقه دیگه رفرش کن.
۶ روی گوشی اندروید نصب کن
همون آدرس بالا رو تو Chrome گوشی باز کن.
منوی «⋮» → افزودن به صفحهٔ اصلی / Install app.
اپ رو باز کن → دکمهٔ 🔔 اجازهٔ اعلان → Allow / اجازه.
تمام ✅ از این به بعد زنگ ساعت هر ۵ دقیقه فایل رو تازه میکند و اپ خودش سر میزند.
من توی این محیط نمیتونم مستقیم به گیتهاب پوش کنم؛ ولی همهٔ فایلها کامل و تستشده تو repo.zip هست. اگه گیر کردی، فقط بگو «مرحلهٔ ۳ گیر کردم» یا یه عکس بفرست.
